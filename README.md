# Homebrew Tap

Public Homebrew tap for Arthuran projects.


## Rivs

```sh
brew install arthuran/tap/rivs
```

Rivs v0.6.2 is built from its private GitHub release tag. Installation requires authorized GitHub SSH access to `arthuran/rivs`; this tap stores no credentials. Homebrew supports Apple Silicon macOS and installs the core `rivs` binary. The tap does not mirror Rivs source or release binaries publicly.
