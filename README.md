# Homebrew Tap

Public Homebrew tap for Arthuran projects.


## Rivs

```sh
brew install arthuran/tap/rivs
```

Rivs is built from its private GitHub source repository. Installation requires authorized GitHub SSH access to `arthuran/rivs`; this tap stores no credentials. Homebrew v1 supports Apple Silicon macOS only and installs the core `rivs` binary. The tap does not mirror Rivs source or release binaries publicly.
